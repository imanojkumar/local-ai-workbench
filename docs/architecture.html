Architecture

A deliberately separated local AI stack that can grow without coupling the UI directly to the model runtime.

Why FastAPI sits in the middle

A direct browser-to-Ollama implementation would be simpler initially, but it would couple the UI to one runtime. FastAPI establishes a stable application boundary for future capabilities.

RAGToolsAgentsPersistenceEvaluationModel routing

Design principles

  1. Local-firstLocal inference is the primary runtime.
  2. Model-agnosticNo dependency on a single model family.
  3. Separation of concernsUI, API, services and runtime remain distinct.
  4. Progressive extensibilityAdd RAG, tools and agents incrementally.
