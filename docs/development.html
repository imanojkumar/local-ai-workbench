Development Guide

A disciplined VS Code, Python and Git workflow for extending the project.

Open the repository

cd /d D:\Ollama_AI_Workbench
code .

Open the repository root as the VS Code workspace.

Virtual environment

.venv\Scripts\activate
python -m pip install -r requirements.txt

Git commands do not require the virtual environment to be active.

Recommended cycle

Edit→Run→Test→Review diff→Stage→Commit→Push

Git essentials

git status
git diff
git add .
git commit -m "Describe the change"
git push

Protect the repository

Do not commit .venv, .env, credentials, tokens, caches or downloaded model artifacts.

Review before every commit

Use git status and git diff --staged before pushing.

Version tags

git tag -a v1.1 -m "Local AI Workbench V1.1"
git push origin v1.1
