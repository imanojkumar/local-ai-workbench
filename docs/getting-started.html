GUIDE 01

Getting Started

From a clean Windows machine to your first local model conversation.

Estimated setup: 10–20 minV1.2

Prerequisites

Install these components before launching the workbench.

Windows 10/11
Python 3.10+
Ollama
Modern browser
Git
VS Code

1. Verify Ollama

Open Command Prompt or PowerShell and confirm the runtime is available.

ollama --version
ollama list
Good to know

An empty ollama list is valid. It only means no model has been installed yet.

2. Start Local AI Workbench

From the project folder, launch:

run.bat

Then open http://127.0.0.1:8000. The launcher normally opens it automatically.

3. Validate the first run

  1. 01
    WebUI loads

    The application shell should render without browser errors.

  2. 02
    Ollama connected

    The status indicator should confirm the local runtime is reachable.

  3. 03
    Model selector is ready

    Installed models appear, or the UI reports that none are installed.

  4. 04
    Model Library opens

    Use it to discover and install a local model.

4. Install a model

Use Model Library, or install directly with Ollama:

ollama pull <model:tag>
Hardware matters

Download size is not the same as RAM or VRAM consumption. Choose a variant appropriate for your machine.

5. Start chatting

Select an installed model, optionally set a system prompt and temperature, enter a prompt and submit. The response streams from Ollama through FastAPI to the browser.

V1.2 saves separate conversations in the browser and organizes them under Pinned, Projects, and Recent. Existing V1.1 single-chat history is migrated automatically on first load.

First response may be slower

A large model can have cold-start/model-loading latency while Ollama loads weights into RAM and/or GPU VRAM. The composer shows elapsed time and time to first token so a slow load is easier to distinguish from a failed request.
