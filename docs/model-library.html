GUIDE 03

Model Library

Discover model families, inspect variants and install them into your local Ollama runtime.

Discovery workflow

Search→Inspect family→Compare variants→Install locally→Chat

Search

Search by model family, for example:

gpt-ossqwengemmallamadeepseek

Variant discovery

Variants can differ in parameter count, quantization, artifact size, context window, input type and local/cloud availability.

Choose by workload, not popularity

Download counts are useful discovery metadata, not a quality score.

Local-only filtering

V1.1 is designed around local Ollama inference. It filters detected cloud-only or non-downloadable variants when local-only filtering is enabled.

Install through Ollama

The installation request remains local:

WebUI→FastAPI→Ollama service→/api/pull

Installed-state detection uses the local /api/tags endpoint.

Catalogue limitation

The local Ollama API does not expose the complete public website catalogue. V1.1 therefore performs best-effort catalogue discovery from public information, which may require maintenance if upstream page structures change.
