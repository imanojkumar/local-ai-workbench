# Local AI Workbench V1.2 UI Preview

This package extends the working V1.1/V1.2 chat UI without changing the core Vanilla JavaScript → FastAPI → Ollama architecture.

## Conversation workspace

- Multiple saved conversations instead of one replaceable transcript.
- Automatic migration of the legacy `lai.messages` conversation into the new workspace store.
- New browser-local workspace key: `lai.workspace.v1`.
- Conversation titles are generated from the first user prompt and can be renamed.
- The selected local model is associated with each conversation.
- System prompt and temperature remain global settings.

## Sidebar

- **Pinned** chats.
- **Projects** with create, rename, collapse/expand, and delete actions.
- **Recent** unpinned chats that are not assigned to a project.
- Chat-title search.
- Per-chat actions: pin/unpin, rename, move to project, return to Recent, and delete.
- Deleting a project does not delete its chats; they return to Recent unless pinned.

## Existing V1.2 chat improvements retained

- Safe assistant Markdown rendering through markdown-it + DOMPurify.
- Code block Copy controls.
- Preparing / Processing / Generating lifecycle states.
- Client-observed elapsed time and time to first token (TTFT).
- Stop preserves partial generated content.

## Persistence notes

Conversation history remains local to the current browser and is not synchronized across devices. Clearing site data/local storage can remove saved chats and projects.

## Validation performed for this package

- `node --check frontend/js/app.js`
- Python compile checks for FastAPI/service modules.
- HTML parser validation for the application and documentation pages.
- CSS brace-balance validation.

A browser automation smoke test was prepared, but the execution environment blocked browser navigation by administrator policy. Manual browser QA is therefore still required on Windows after extraction.
